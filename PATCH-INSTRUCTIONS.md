# Device Care brand icon patch

Apply this patch at the repository root. It replaces only these two integration brand assets:

- `custom_components/device_care/brand/icon.png` (256 × 256)
- `custom_components/device_care/brand/icon@2x.png` (512 × 512)

The PNGs have transparent backgrounds. Home Assistant 2026.3 and newer can serve branding shipped inside a custom integration. This patch does not change release metadata, code, or the sidebar icon.
